# exam-answer 开卷考试答题技能

一个可以发给同学用的开卷考试答题技能。装进能访问腾讯文档的 AI 助手（agent）后，第一次用某门课把讲义拉到本机存好，之后考场上贴题或发试卷照片，它读本机资料直接给出可以手抄的答案。计算题按"假设、公式、代入、结果带单位"给足过程分。

- **落地一次，之后都读本机。** 同一门课只从腾讯文档拉一次，换会话、换天、重启都不用再拉；开场是读两个本地文件的时间。
- 纯提示词技能：不装 Python、Node 或任何依赖；读腾讯文档用的是宿主已有的能力。
- 连上就能用：优先支持 WorkBuddy 的腾讯文档能力，能自己发现课程文件夹，不必先设置资料源或说"开考"。
- 答案纯文本输出：不加粗、无星号井号横线、不写出处，可以有（1）（2）（3）这类手写序号。
- 资料全在腾讯文档，靠使用者自己的账号读取；本机缓存只在自己机器上。

版本：0.4.1（contract: exam-answer/v1）

## 平台支持

| 平台 | 状态 | 说明 |
|---|---|---|
| Windows + WorkBuddy | 已实测 | 快通道、落地、检索全链路跑过 |
| macOS + WorkBuddy | 未实测，按同构推断 | 技能目录、缓存目录同一套写法；差异只在命令名，macOS 用 `python3`，Windows 用 `python`。装完先跑自检，读到导览即链路通 |
| Linux + WorkBuddy | 未实测 | 同上，解释器用 `python3` |
| 其他 agent（Claude Code、Cursor 等） | 未测 | 走通用路径，按功能找列目录和读正文工具，没有快通道 |

macOS 上唯一容易卡住的地方是解释器名。技能里命令一律写 `<PY>` 占位，按平台换成 `python3` 或 `python`；这两个都是 WorkBuddy 自带的运行时，不需要额外安装。真找不到时进 `~/.workbuddy/binaries/python/` 按版本目录找，用全路径调用。

## 前置条件

1. 你的 agent 能访问腾讯文档。WorkBuddy 优先：内置腾讯文档能力，连上后技能走快通道，自动发现课程文件夹；其他 agent 配置腾讯文档 MCP，按功能找工具，同样可用。
2. 课程资料按约定整理在腾讯文档里（可以是一个共享文件夹，也可以是散落在"我的文档"里的课程文件夹；快通道会按课程名搜文件夹）：
   - 每门课一个子文件夹，文件夹名即课程名。
   - 每门课里有"00"开头的导览一篇，"01"到"99"两位数字开头的课次讲义若干篇；同一标题的旧稿自动跳过，只取最新。
   - 可选："答案册""口径表"（可以用本技能的"出答案册"指令生成）。
   - 其余文件（课件、PDF、在线幻灯片、录音、未编号文档）都算按需资料，默认不落地，答题需要时才拉，拉过就存下来。
3. 单份按需资料建议不超过 1.5 万字符，超过的在 agent 里只能读到开头；幻灯片除外，可按页读。资料太大时把它拆成几份，或只保留与考点相关的部分。
4. 本机用户主目录下可写 `.exam-answer/` 文件夹：存资料源链接、本人情况，以及每门课的资料缓存。写不进去也能用，只是每次开考还得重拉一遍——把链接随消息发来，或让技能按课程名自动发现。
5. 想答好"结合本企业或本项目"的题，准备一份个人材料：直接贴一段文字，或一份报名表、简历、项目经历说明（Word、PDF、图片都行）。材料只在你自己的会话里读，不上传、不入库。

## 安装

### 方式一：把这句话发给你的 agent

GitHub 版（WorkBuddy 及多数 agent）：

    请帮我安装一个技能：从 https://github.com/petra1218/exam-answer 克隆仓库，把 exam-answer 技能目录复制到你的技能目录，装完执行一次自检。

GitCode 版（国内网络）：

    请帮我安装一个技能：从 https://gitcode.com/petra1218/exam-answer 克隆仓库，把 exam-answer 技能目录复制到你的技能目录，装完执行一次自检。

### 方式二：手动安装

    git clone https://github.com/petra1218/exam-answer.git

把仓库里的技能文件（SKILL.md 和 references/）复制到你的 agent 技能目录下的 exam-answer/ 文件夹。各 agent 的技能目录见 INSTALL.md。

各平台都是用户主目录下的 .workbuddy/skills/exam-answer/：

    ~/.workbuddy/skills/exam-answer/

安装命令见文末"安装命令参考"。

关于 npx skills add：实测它能识别本仓库并克隆成功，但它支持的 79 个 agent 里没有 WorkBuddy，会把技能装到项目内的 .agents/skills/，WorkBuddy 读不到。WorkBuddy 用户请用上面的克隆复制方式；其他 agent（如 Claude Code、Cursor 等）可用 `npx skills add petra1218/exam-answer`，交互选择 agent，或非交互加 `--agent <名称> -y`。

## 怎么用

**最常用：贴题或发试卷照片就行。**

同一门课第一次贴题时，技能会自己判断腾讯文档能不能用：能就把这门课的导览、讲义、答案册、口径表拉到本机存好，再答题；推不出是哪门课，只问一句"哪门课"。**这一步只发生一次**——之后贴题直接读本机，不联网。腾讯文档确实没接上、本机也没有这门课的资料时，会提示需要连接器，并说明这次按通用知识作答、把握低。

下面的指令都是可选的快捷方式，不是必做步骤：

1. 自检：说"自检"，确认腾讯文档接通、资料源可读、哪些课已经落地。自检单独开一个会话，只读每门课的导览，不读课件，不报字符数。想抽查一份课件是否读得全，说"深度自检"。首次使用建议先跑。
2. 设置资料源：把课程共享根文件夹的链接发给 agent，说"设置资料源，链接是这个"（链接最后一段就是文件夹 ID）。一般是可选的，按课程名能搜到就不用设。想答好"结合本企业"的题，再设本人情况，三种给法任选：贴一段自己企业或项目的情况；发一份现成的个人材料（报名表、简历、项目经历说明，Word、PDF、图片都行）说"把这份材料存成本人情况"，agent 读后只摘与答题有关的事实；或说"更新本人情况"改已有内容。
3. 准备考试：想显式做一次落地时说"准备考试 软件项目管理"。它只做落地，把资料存到本机、报个篇数就停，**不生成答案册**（答案册是几十道题的产出，要说"出答案册"才做）。课件、PDF、幻灯片这类按需资料这时只登记不落地。
4. 开考：说"开考 软件项目管理"，读本机清单和导览，秒开。课程名可以用简称或部分字样，agent 会做包含匹配。
5. 更新资料：老师新发了讲义、改了课件，说"更新资料 软件项目管理"，agent 重新列一次目录比对，只重拉变过的篇目。不说就不比对——每次开考都比对是拿考场时间换一个大概率没变的检查。
6. 出答案册（考前准备，可选）：说"出答案册 某课程"，得到一份按课次预测的答案册和选择题口径表。内容会写进本机，下次开考直接用到；同时给你一份 Markdown 文稿，自己粘贴到腾讯文档分享给同学。

> 提示：连接腾讯文档不等于讲义已经在会话里，但现在不需要你手工搬运——第一次贴题时技能会自己完成落地，之后一直读本机。只有你明确说"不用讲义"，它才会跳过。

## 资料目录约定

见"前置条件"第 2 条。要点：一门课一个文件夹、导览"00"打头、讲义两位数字编号打头；其余一律按需资料，不按标题前缀认。文件夹里既没有导览也没有讲义的算非课程文件夹，跳过。不符合约定的文件不阻断使用。

## 本机缓存长什么样

落地后的资料在用户主目录下，一门课一个文件夹，文件平铺：

    ~/.exam-answer/
      资料源.txt              你自己设的共享链接，一行一个
      本人情况.md             结合本企业类题用的事实
      课程/
        软件项目管理/
          清单.md             抓取时间、每篇的来源 ID 和状态
          导览.md
          01 绪论.md
          02 项目启动.md
          答案册.md
          口径表.md
          按需 第1章课件.md

`清单.md` 记了每篇的 file_id 和修改时间，"更新资料"靠它比对。缓存只在本机，不进仓库、不上传、不发给别人。换机器或重装技能要重新拉一次。

## 更新与卸载

更新：重新执行安装（或 git pull 后重新复制），版本号见 SKILL.md 头部，改动见 CHANGELOG.md。

卸载：删除技能目录（WorkBuddy 为 ~/.workbuddy/skills/exam-answer/）。可选：删除用户主目录下的 .exam-answer/ 文件夹（存的是你自己的资料源链接、本人情况和课程缓存，与技能仓库无关；不删也不影响以后重装再用）。

## 隐私说明

- 本技能仓库不含任何课程资料：不讲义、不课件、不试题，也没有真实的人名、学校名。
- 读取课程资料用的是使用者自己的腾讯文档账号和权限，技能作者接触不到。
- 资料源链接、本人情况和课程缓存只存在使用者自己机器的用户主目录 .exam-answer/ 下，不上传、不入库。
- 个人材料只在本次会话里读；本人情况只用于"结合本企业或本项目"题取事实，不写进答案册、口径表、自检表和准备考试汇总。
- 自动发现若需要列根目录，会看到使用者的其它文件夹标题；这些标题不写进任何输出、不进汇总、不拿来作答。能推出课程名时优先按课程名搜文件夹，避免列根目录。
- 出答案册的结果先写本机，再由用户自己决定是否粘贴到腾讯文档，技能不自动写入。

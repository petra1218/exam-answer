# exam-answer 开卷考试答题技能

一个可以发给同学用的开卷考试答题技能。装进能访问腾讯文档的 AI 助手（agent）后，考场上说一句"开考 某课程"，它就把这门课的讲义从腾讯文档装进上下文；你贴题或发试卷照片，它直接给出可以手抄的答案。计算题按"假设、公式、代入、结果带单位"给足过程分。

- 纯提示词技能：不装 Python、Node 或任何依赖。
- 答案纯文本输出：不加粗、无星号井号横线、不写出处，可以有（1）（2）（3）这类手写序号。
- 资料全在腾讯文档，靠使用者自己的账号读取。

版本：0.2.0（contract: exam-answer/v1）

## 前置条件

1. 你的 agent 能访问腾讯文档（WorkBuddy 内置腾讯文档插件；其他 agent 配置腾讯文档 MCP）。
2. 课程资料按约定整理在腾讯文档的一个共享文件夹里，并共享给使用者的账号：
   - 每门课一个子文件夹，文件夹名即课程名。
   - 每门课里有"00"开头的导览一篇，"01"到"99"两位数字开头的课次讲义若干篇；同一标题的旧稿自动跳过，只取最新。
   - 可选："答案册""口径表"（可以用本技能的"出答案册"指令生成）。
   - 其余文件（课件、PDF、在线幻灯片、录音、未编号文档）都算按需资料，默认不装，答题需要时才读。命名不必符合某个前缀，按文件类型识别。
3. 单份按需资料建议不超过 1.5 万字符，超过的在 agent 里只能读到开头；幻灯片除外，可按页读。资料太大时把它拆成几份，或只保留与考点相关的部分。
4. 本机用户主目录下可写 .exam-answer/ 文件夹（存资料源链接和本人情况）。写不进去也能用，每次开考把链接一起发来即可。
5. 想答好"结合本企业或本项目"的题，准备一份个人材料：直接贴一段文字，或一份报名表、简历、项目经历说明（Word、PDF、图片都行）。材料只在你自己的会话里读，不上传、不入库。

## 安装

### 方式一：把这句话发给你的 agent

GitHub 版（WorkBuddy 及多数 agent）：

    请帮我安装一个技能：从 https://github.com/petra1218/exam-answer 克隆仓库，把 exam-answer 技能目录复制到你的技能目录，装完执行一次自检。

GitCode 版（国内网络）：

    请帮我安装一个技能：从 https://gitcode.com/petra1218/exam-answer 克隆仓库，把 exam-answer 技能目录复制到你的技能目录，装完执行一次自检。

### 方式二：手动安装

    git clone https://github.com/petra1218/exam-answer.git

把仓库里的技能文件（SKILL.md 和 references/）复制到你的 agent 技能目录下的 exam-answer/ 文件夹。各 agent 的技能目录见 INSTALL.md。

各平台都是用户主目录下的 .workbuddy/skills/exam-answer/：

    ~/.workbuddy/skills/exam-answer/

安装命令见文末"安装命令参考"。

关于 npx skills add：实测它能识别本仓库并克隆成功，但它支持的 79 个 agent 里没有 WorkBuddy，会把技能装到项目内的 .agents/skills/，WorkBuddy 读不到。WorkBuddy 用户请用上面的克隆复制方式；其他 agent（如 Claude Code、Cursor 等）可用 `npx skills add petra1218/exam-answer`，交互选择 agent，或非交互加 `--agent <名称> -y`。

## 五步使用

1. 自检。对 agent 说"自检"。确认腾讯文档接通、资料源可读。自检单独开一个会话，不要和开考共用；它只读每门课的导览，不读课件，不报字符数。想抽查一份课件是否读得全，说"深度自检"。首次使用建议先跑。
2. 设置资料源。把课程共享根文件夹的链接发给 agent，说"设置资料源，链接是这个"（链接最后一段就是文件夹 ID）。想答好"结合本企业"的题，再设本人情况，三种给法任选：贴一段自己企业或项目的情况；发一份现成的个人材料（报名表、简历、项目经历说明，Word、PDF、图片都行）说"把这份材料存成本人情况"，agent 读后只摘与答题有关的事实；或说"更新本人情况"改已有内容。
3. 开考。考前或考场上说"开考 软件项目管理"（默认全量，一轮并行装完导览、讲义、答案册、口径表），或"开考 软件项目管理 精简"（只装导览、答案册、口径表，讲义按题目关键词对课次标题选最相关的 1 到 3 篇读）。课程名可以用简称或部分字样，agent 会做包含匹配。课件、PDF、幻灯片默认不装，只有三种情况才读：已装资料里找不到考点、讲义只有名称没展开、题目要公式或步骤的标准写法。
4. 答题。贴题目文字或发试卷照片，可以一次发多题。选择题出一张答案表，其余按速查表直接给答案。答案只用讲义里明确写出的要点，不自己拼新清单。
5. 考前准备（可选）。说"出答案册 某课程"，得到一份按课次预测的答案册和选择题口径表文稿，自己粘贴到腾讯文档，下次开考自动装进去。

## 资料目录约定

见"前置条件"第 2 条。要点：一门课一个文件夹、导览"00"打头、讲义两位数字编号打头；其余一律按需资料，不按标题前缀认。文件夹里既没有导览也没有讲义的算非课程文件夹，跳过。不符合约定的文件不阻断使用。

## 更新与卸载

更新：重新执行安装（或 git pull 后重新复制），版本号见 SKILL.md 头部，改动见 CHANGELOG.md。
卸载：删除技能目录（WorkBuddy 为 ~/.workbuddy/skills/exam-answer/）。可选：删除用户主目录下的 .exam-answer/ 文件夹（存的是你自己的资料源链接和本人情况，与技能仓库无关）。

## 隐私说明

- 本技能仓库不含任何课程资料：不讲义、不课件、不试题，也没有真实的人名、学校名。
- 读取课程资料用的是使用者自己的腾讯文档账号和权限，技能作者接触不到。
- 资料源链接和本人情况只存在使用者自己机器的用户主目录 .exam-answer/ 下，不上传、不入库。
- 个人材料只在本次会话里读；本人情况只用于"结合本企业或本项目"题取事实，不写进答案册、口径表、自检表和开考汇总。
- 出答案册的结果由用户自己粘贴到腾讯文档，技能不自动写入。

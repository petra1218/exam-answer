# exam-answer 开卷考试答题技能

一个可以发给同学用的开卷考试答题技能。装进能访问腾讯文档的 AI 助手（agent）后，考场上说一句"开考 某课程"，它就把这门课的讲义从腾讯文档装进上下文；你贴题或发试卷照片，它直接给出可以手抄的答案。计算题按"系数公式、代入、系数值、结果"四行写法给足过程分。

- 纯提示词技能：不装 Python、Node 或任何依赖。
- 答案纯文本输出：不加粗、无列表符号、不写出处，抄上去就用。
- 资料全在腾讯文档，靠使用者自己的账号读取。

版本：0.1.0（contract: exam-answer/v1）

## 前置条件

1. 你的 agent 能访问腾讯文档（WorkBuddy 内置腾讯文档插件；其他 agent 配置腾讯文档 MCP）。
2. 课程资料按约定整理在腾讯文档的一个共享文件夹里，并共享给使用者的账号：
   - 每门课一个子文件夹，文件夹名即课程名。
   - 每门课里有"00 课程导览"一篇。
   - 课次讲义若干篇，标题以两位数字开头（如"01 0905 ……"）；同一标题的旧稿会被自动跳过，只取最新。
   - 可选："答案册""口径表"（可以用本技能的"出答案册"指令生成）。
   - 课件为 PDF 或在线幻灯片，标题以"第N章"开头，默认不装入，答题需要时才读。

## 安装

### 方式一：把这句话发给你的 agent

GitHub 版（WorkBuddy、支持 npx skills 的 agent）：

    请帮我安装一个技能：用 npx skills add petra1218/exam-answer 安装，装完执行一次自检。

GitCode 版（国内网络）：

    请帮我安装一个技能：从 https://gitcode.com/petra1218/exam-answer 克隆仓库，把其中的 exam-answer 技能目录复制到你的技能目录，装完执行一次自检。

### 方式二：手动安装

    git clone https://github.com/petra1218/exam-answer.git

把仓库里的技能文件（SKILL.md 和 references/）复制到你的 agent 技能目录下的 exam-answer/ 文件夹。各 agent 的技能目录见 INSTALL.md。

WorkBuddy 的目录是：

    C:\Users\<你的用户名>\.workbuddy\skills\exam-answer\

（macOS / Linux 为 ~/.workbuddy/skills/exam-answer/）

安装命令在本机实际验证情况见文末"已验证的安装命令"。

## 五步使用

1. 自检。对 agent 说"自检"。确认腾讯文档接通、资料源可读。首次使用建议先跑。
2. 设置资料源。把课程共享根文件夹的链接发给 agent，说"设置资料源，链接是这个"。想答好"结合本企业"的题，再贴一段自己企业或项目的情况，说"存成本人情况"。
3. 开考。考前或考场上说"开考 工程经济学"（默认全量装讲义）或"开考 工程经济学 精简"（只装导览、答案册、口径表，讲义按题加载）。
4. 答题。贴题目文字或发试卷照片，可以一次发多题。选择题出一张答案表，其余按题型范式直接给答案。
5. 考前准备（可选）。说"出答案册 某课程"，得到一份按课次预测的答案册和选择题口径表文稿，自己粘贴到腾讯文档，下次开考自动装进去。

## 资料目录约定

见"前置条件"第 2 条。要点：一门课一个文件夹、导览打头、讲义两位数字编号打头、课件"第N章"打头。不符合约定的文件不阻断使用，自检报告里会提示。

## 更新与卸载

更新：重新执行安装（或 git pull 后重新复制），版本号见 SKILL.md 头部，改动见 CHANGELOG.md。
卸载：删除技能目录（WorkBuddy 为 ~/.workbuddy/skills/exam-answer/）。可选：删除用户主目录下的 .exam-answer/ 文件夹（存的是你自己的资料源链接和本人情况，与技能仓库无关）。

## 隐私说明

- 本技能仓库不含任何课程资料：不讲义、不课件、不试题，也没有真实的人名、学校名。
- 读取课程资料用的是使用者自己的腾讯文档账号和权限，技能作者接触不到。
- 资料源链接和本人情况只存在使用者自己机器的用户主目录 .exam-answer/ 下，不上传、不入库。
- 出答案册的结果由用户自己粘贴到腾讯文档，技能不自动写入。

# 计算命令（三步走、命令模板、复核）

计算题要算数时读。本文是命令模板，运行时不依赖任何脚本，命令现敲现用。系数表另见 《复利系数表》，展开式见 《计算题写法》 第三节。

## 一、三步走

1. 能执行命令就用一行命令算。Windows 的 Git Bash、macOS、Linux 用 awk；Windows 的 PowerShell 和命令提示符用 [math] 表达式。
2. 不能执行命令就查 《复利系数表》：六个系数、13 档利率、26 档期数。
3. 表里没有的利率或期数，用展开式手算（见 《计算题写法》 第三节）。

答案里的数从一而终：用表值就一路用表值，用命令值就一路用命令值，不在同一道题里混用。

命令里改三个数就能用：利率、期数、金额。输出就是系数值或结果，填进 《计算题写法》 写法的代入行或结果行。

## 二、六大系数命令模板

下面每对命令算同一个量，PS 与 awk 结果应与系数表一致。

Windows（[math] 表达式，直接粘贴执行）：

    # (F/P, i, n) 一次支付终值：100 元，10%，5 期
    [math]::Round(100*[math]::Pow(1.10,5),4,[System.MidpointRounding]::AwayFromZero)

    # (P/F, i, n) 一次支付现值
    [math]::Round(100/[math]::Pow(1.10,5),4,[System.MidpointRounding]::AwayFromZero)

    # (F/A, i, n) 等额支付终值：年金 100，10%，5 期
    [math]::Round(100*(([math]::Pow(1.10,5)-1)/0.10),4,[System.MidpointRounding]::AwayFromZero)

    # (A/F, i, n) 偿债基金：终值 100
    [math]::Round(0.10/([math]::Pow(1.10,5)-1)*100,4,[System.MidpointRounding]::AwayFromZero)

    # (A/P, i, n) 资金回收：现值 100
    [math]::Round((0.10*[math]::Pow(1.10,5))/([math]::Pow(1.10,5)-1)*100,4,[System.MidpointRounding]::AwayFromZero)

    # (P/A, i, n) 年金现值：年金 100
    [math]::Round(([math]::Pow(1.10,5)-1)/(0.10*[math]::Pow(1.10,5))*100,4,[System.MidpointRounding]::AwayFromZero)

macOS、Linux、Windows 的 Git Bash（awk，直接粘贴执行）：

    awk 'BEGIN{printf "%.4f", 100*(1.10^5)}'
    awk 'BEGIN{printf "%.4f", 100/(1.10^5)}'
    awk 'BEGIN{printf "%.4f", 100*((1.10^5-1)/0.10)}'
    awk 'BEGIN{printf "%.4f", 0.10/(1.10^5-1)*100}'
    awk 'BEGIN{printf "%.4f", (0.10*1.10^5)/(1.10^5-1)*100}'
    awk 'BEGIN{printf "%.4f", (1.10^5-1)/(0.10*1.10^5)*100}'

去掉 100* 就是纯系数值。利率 10% 写 0.10 或 1.10，7.5% 写 0.075 或 1.075。

为什么要写 AwayFromZero：[math]::Round 默认是银行家舍入（五成双），2.5 会舍成 2；系数表用的是远离零方向，2.5 进成 3。两者不一致，末位会对不上。带 [System.MidpointRounding]::AwayFromZero 才和表一致。

awk 的 printf 同样是银行家舍入，不是四舍五入：实测 2.5→2、3.5→4、0.12355→0.1235。绝大多数格子末位不受影响，真要拿到和表一致的末位，用离线舍入表达式自己收（系数都是正数）：把 `printf "%.4f", x` 换成 `printf "%.4f", int(x*10000+0.5)/10000`，五位小数把 10000 换成 100000。实测 P/A,10%,5 用这个写法得 3.7908，与表一致。

为什么允许差一位：表值是舍入值，命令是精确值，末位天然可能差 0.0001。复核按相对误差 0.05% 判，不因末位差一位就重算。

## 三、常见题型命令模板

### 有效年利率（名义 12%，半年计息）

    [math]: [math]::Round([math]::Pow(1+0.12/2,2)-1,6,[System.MidpointRounding]::AwayFromZero)
    awk:    awk 'BEGIN{printf "%.6f", (1+0.12/2)^2-1}'

### 净现值（-2000 万元，1 到 5 年末各 600，10%）

    [math]: [math]::Round(-2000+600*(([math]::Pow(1.10,5)-1)/(0.10*[math]::Pow(1.10,5))),4,[System.MidpointRounding]::AwayFromZero)
    awk:    awk 'BEGIN{printf "%.4f", -2000+600*((1.10^5-1)/(0.10*1.10^5))}'

### 净年值（NPV 已知 274.48，10%，5 年）

    [math]: [math]::Round(274.48*(0.10*[math]::Pow(1.10,5))/([math]::Pow(1.10,5)-1),4,[System.MidpointRounding]::AwayFromZero)
    awk:    awk 'BEGIN{printf "%.4f", 274.48*(0.10*1.10^5)/(1.10^5-1)}'

### 投资回收期（静态，前 3 年累计 -100，第 4 年净流 250）

    [math]: [math]::Round(3+100/250,2,[System.MidpointRounding]::AwayFromZero)
    awk:    awk 'BEGIN{printf "%.2f", 3+100/250}'

不规则现金流就逐年累加：

    awk 'BEGIN{split("-2000 600 600 600 600 600",a," ");c=0;for(t=0;t<6;t++){c+=a[t+1]/1.10^t};printf "%.2f",c}'

### 决策树（两方案：销路好 0.7 / 差 0.3，年限 10 年，投资 290 / 170）

模板补全到"期望年损益 × 年限 − 投资"，两方案一次算完：

    awk 'BEGIN{e1=0.7*100+0.3*(-30); e2=0.7*45+0.3*10; printf "甲=%.1f 乙=%.1f\n",e1*10-290,e2*10-170}'

    [math]: $e1=0.7*100+0.3*(-30); $e2=0.7*45+0.3*10; "甲="+[math]::Round($e1*10-290,2,[System.MidpointRounding]::AwayFromZero)+" 乙="+[math]::Round($e2*10-170,2,[System.MidpointRounding]::AwayFromZero)

### 盈亏平衡（固定 120000，单价 200，单位变动 120）

    [math]: [math]::Round(120000/(200-120),0,[System.MidpointRounding]::AwayFromZero)
    awk:    awk 'BEGIN{printf "%.0f", 120000/(200-120)}'

### 反求利率（5000 = 1500 每年，5 年，二分法解 i）

    [math]: $lo=0.0;$hi=1.0;for($k=0;$k -lt 200;$k++){$m=($lo+$hi)/2;$v=1500*(([math]::Pow(1+$m,5)-1)/($m*[math]::Pow(1+$m,5)));if($v -gt 5000){$lo=$m}else{$hi=$m}};[math]::Round(($lo+$hi)/2*100,2,[System.MidpointRounding]::AwayFromZero)

    awk:    awk 'BEGIN{lo=0;hi=1;for(k=0;k<200;k++){m=(lo+hi)/2;v=1500*((1+m)^5-1)/(m*(1+m)^5);if(v>5000)lo=m;else hi=m};printf "%.2f%%",(lo+hi)/2*100}'

**二分方向随方程反过来，这是最容易错的一处。** 现值方程里 v 随 m 增大而减小，终值方程里 v 随 m 增大而增大，两种方程的判断方向相反；照抄另一套方向会一路收敛到 100%（实测：5000 五年后变 6450，用现值方向算出 100%，反转后才是 5.22%）。

- 现值方程（A 求 i、P 求 i）：v 随 m 增大而减小，所以 `v>目标 → lo=m`。
- 终值方程（P、F 求 i）：v 随 m 增大而增大，所以 `v<目标 → lo=m`，方向反过来。

终值方程（5000 五年后 6450，求 i）：

    [math]: $lo=0.0;$hi=1.0;for($k=0;$k -lt 200;$k++){$m=($lo+$hi)/2;$v=5000*[math]::Pow(1+$m,5);if($v -lt 6450){$lo=$m}else{$hi=$m}};[math]::Round(($lo+$hi)/2*100,2,[System.MidpointRounding]::AwayFromZero)

    awk:    awk 'BEGIN{lo=0;hi=1;for(k=0;k<200;k++){m=(lo+hi)/2;v=5000*(1+m)^5;if(v<6450)lo=m;else hi=m};printf "%.2f%%",(lo+hi)/2*100}'

结果 5.22%。解完代回去核一次：5000 按 5.22% 五年是 6442，与 6450 差在容差内即通过。

## 四、复核（按题型给办法，带容差）

为什么加容差：表值是四位（或五位）舍入值，命令是精确值，末位天然对不上。相对误差 0.05% 以内算通过，不用重算。

- 系数题：查互逆关系 (F/P)×(P/F)=1、(F/A)×(A/F)=1、(A/P)×(P/A)=1；再查按期间利率和按有效年利率算同一题结果是否相等。互逆命令：

    [math]: [math]::Round([math]::Pow(1.10,5)*(1/[math]::Pow(1.10,5)),4,[System.MidpointRounding]::AwayFromZero)
    awk:    awk 'BEGIN{printf "%.4f", (1.10^5)*(1/1.10^5)}'

    [math]: [math]::Round((([math]::Pow(1.10,5)-1)/0.10)*(0.10/([math]::Pow(1.10,5)-1)),4,[System.MidpointRounding]::AwayFromZero)
    awk:    awk 'BEGIN{printf "%.4f", ((1.10^5-1)/0.10)*(0.10/(1.10^5-1))}'

    # 半年计息 12% 对比有效年利率 12.36% 算同一笔终值应相等
    [math]: [math]::Round(100*[math]::Pow(1+0.12/2,10),4,[System.MidpointRounding]::AwayFromZero)
    awk:    awk 'BEGIN{printf "%.4f", 100*(1.1236^5)}'

- 决策树、盈亏平衡、回收期：不用互逆关系。换一种算法再算一遍（决策树用逐年现金流展开核对期望，盈亏平衡用"收入=成本"反代，回收期用累计现金流表核），或把讲义例题的原始数字代回，看是否得到讲义里的结果。

复核不过就重算，不用向用户解释复核过程，答案里只呈现 《计算题写法》 的写法本身。

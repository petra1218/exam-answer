# 故障排查

工具调用失败、读不到、输出被切掉、截断、超限时读。每条：现象、缺什么、去哪里补、补完从哪一步重试。

工具名认功能不认名字。本服务实测：列目录、查文档结构用点号（manage.folder_list、doc.resolve_document_structure），其余用下划线（get_content、get_user_info、slide_get_info、slide_get_page_info）。不同 agent 可能不同，按功能对上就行。

## 1. 找不到腾讯文档工具

现象：会话的工具列表里找不到能"列目录、读正文"腾讯文档文件的工具。
缺什么：当前 agent 没接入腾讯文档能力。
去哪里补：
- WorkBuddy：在技能或插件设置里启用"腾讯文档"插件并登录腾讯文档账号。
- 其他 agent：在它的 MCP 配置里添加腾讯文档 MCP 服务器。
补完从哪一步重试：自检第 2 步。

## 2. 取账号失败

现象：取账号工具报鉴权失败或令牌过期。
缺什么：腾讯文档登录态。
去哪里补：在宿主 agent 里重新授权或重新登录腾讯文档连接器。
补完从哪一步重试：自检第 3 步。

## 3. 列目录无权限

现象：列目录报权限错误，或返回空列表但用户说里面有东西。
缺什么：这个文件夹对当前登录的账号没有读取权限。共享链接 ≠ 当前账号有权限，链接分享范围可能不含此账号。
去哪里补：让资料主人把共享权限开到当前登录腾讯文档的账号，或让用户用有权限的账号登录。
补完从哪一步重试：自检第 5 步，或"开考"第 1 步。
注意：不要反复重试同一个无权限链接，权限没变结果不会变。

## 4. 工具输出中途被切掉（JSON 不完整、结尾突然断开）

现象：一次调用返回超大，输出从中间断开，JSON 解析不了，或结尾没有正常收束。
缺什么：单次工具输出有上限，一次递归列多层目录会把返回撑爆；浅层列举每页很小，不会撞。别的 agent 上限可能不同。
去哪里补：这次调用作废，不要拿半截结果用。改用浅层列举（不带 max_depth，每页 20 条，finish 为 false 就把 start 加 20 再列），或一次读更少的篇数。翻到空页（返回 0 条）就停，即使 finish 仍是 false——条目数正好是 20 倍时 finish 可能一直为 false，别死循环。
补完从哪一步重试：自检第 5 步、"开考"第 2 步或"开考"第 3 步，按作废的那次调用是哪一步来定。

## 5. 课程文件夹找不到

现象：资料源里没有用户说的课程名。
缺什么：课程名对不上，或资料源链接不对。
去哪里补：课程名用包含匹配，简称或部分字样也能对上完整课程名；仍对不上就列出实际有哪些课程让用户确认；多个资料源时逐个查完再报。链接最后一段是 folder_id，别取错。
补完从哪一步重试："开考"第 1 步。

## 6. 讲义读不到或读出来是空的

现象：get_content 返回空、报错或明显不是讲义内容。
缺什么：单篇文档权限、文档类型不支持、或 file_id 取错。
去哪里补：换目录里该文档的 id 重试一次；仍失败就跳过这篇，列进"未装"，不阻断开考。实测偶发读超时，重试即恢复。
补完从哪一步重试："开考"第 3 步。

## 7. 长文档读不全（截断）

现象：get_content 只有 file_id，没有分页参数，也没有截断标志；超过上限只拿到开头（约 1.6 万汉字）。PDF 正文里带 `<!-- page N -->` 页标记，读到第几页看标记；一个页标记都没有的，可能没有完整读出。
缺什么：工具侧对单次输出的截断，不是权限问题。
去哪里补：按 SKILL.md"读取"一节的截断统一处理——单篇读不全，保留读到的部分，继续装其余篇目，汇总里点明哪篇可能不全。PDF 报"读到第 N 页"并请用户对照实际页数。超过 60 页的在线幻灯片改用 slide_get_page_info 按页读，每轮并行 20 页，读到够回答就停（整篇读幻灯片没有页标记，243 页章节整篇读会超限）。
补完从哪一步重试："开考"第 3 步继续装其余篇目。只有装入后已经无法稳定作答（前后文丢失、工具报超长）才整体改用精简模式并重装，见下一条。

## 8. 装入后超出上下文

现象：全量装入后输出质量下降、前后文丢失、或工具报超长。
缺什么：上下文容量。
去哪里补：整体改用精简模式并重装——只装导览、答案册、口径表，讲义按题加载；告诉用户改了模式。多门课同时开考时改成一门一门来。精简模式按题目关键词对课次标题选最相关的 1 到 3 篇读，标题判断不出就问用户或建议改全量。
补完从哪一步重试："开考"第 3 步（精简分支）。
注意：单篇截断不触发本条，按第 7 条处理，别一遇截断就改精简。

## 9. 照片看不清

现象：题面数字、单位、选项糊或反光。
缺什么：图像质量。
去哪里补：用【?】标出看不清的字，在答复开头集中列出问用户。数字和选项读两遍，宁问勿猜。
补完从哪一步重试：答题第 1 步（用户回复后重新转写该处）。

## 10. 答案册生成中断

现象：出答案册过程中途失败。
缺什么：看具体报错落在上面哪条。
去哪里补：按对应条目处理。
补完从哪一步重试：已写好的课次保留，从失败的课次继续，不从头重写。

## 11. 沙箱写不进 .exam-answer/

现象：保存资料源或本人情况时报只读或权限拒绝。
缺什么：文件系统写权限。
去哪里补：不写了。告诉用户每次开考时把链接和本人情况一起发来，流程照常。
补完从哪一步重试："设置资料源"第 2 步降级路径，直接进入"开考"。

## 12. 个人材料读不了

现象：用户发来报名表、简历一类的 Word、PDF 或图片，读不出来、格式打不开、或工具不支持。
缺什么：agent 这一侧读这份文件的能力，不是用户给错材料。
去哪里补：不猜内容。请用户把材料里的关键事实粘贴成文字，或另存成纯文本、PDF 再发一次；按"设置本人情况"第 3 步的三种给法收。材料只在本次会话里读，不上传、不入库。
补完从哪一步重试："设置资料源"第 3 步（本人情况分支）。

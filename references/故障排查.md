# 故障排查

工具调用失败、读不到、截断、超限时读。每条：现象、缺什么、去哪里补、补完从哪一步重试。

## 1. 找不到腾讯文档工具

现象：会话的工具列表里找不到能"列目录、读正文"腾讯文档文件的工具。不同 agent 的工具名前缀不同，认功能不认名字：能按功能对上就算找到。
缺什么：当前 agent 没接入腾讯文档能力。
去哪里补：
- WorkBuddy：在技能或插件设置里启用"腾讯文档"插件并登录腾讯文档账号。
- 其他 agent：在它的 MCP 配置里添加腾讯文档 MCP 服务器。
补完从哪一步重试：自检第 2 步。

## 2. 取账号失败

现象：取账号工具报鉴权失败或令牌过期。
缺什么：腾讯文档登录态。
去哪里补：在宿主 agent 里重新授权或重新登录腾讯文档连接器。
补完从哪一步重试：自检第 3 步。

## 3. 列目录无权限

现象：列目录报权限错误，或返回空列表但用户说里面有东西。
缺什么：这个文件夹对当前登录的账号没有读取权限。共享链接 ≠ 当前账号有权限，链接分享范围可能不含此账号。
去哪里补：让资料主人把共享权限开到当前登录腾讯文档的账号，或让用户用有权限的账号登录。
补完从哪一步重试：自检第 5 步，或"开考"第 1 步。
注意：不要反复重试同一个无权限链接，权限没变结果不会变。

## 4. 课程文件夹找不到

现象：资料源里没有用户说的课程名。
缺什么：课程名对不上，或资料源链接不对。
去哪里补：列出实际有哪些课程让用户确认；多个资料源时逐个查完再报。
补完从哪一步重试："开考"第 1 步。

## 5. 讲义读不到或读出来是空的

现象：get_content 返回空、报错或明显不是讲义内容。
缺什么：单篇文档权限、文档类型不支持、或 file_id 取错（链接最后一段才是 file_id）。
去哪里补：换目录树里该文档的 id 重试一次；仍失败就跳过这篇并在"没装的部分"里报出来，不阻断开考。
补完从哪一步重试："开考"第 3 步。

## 6. 读取被截断（长 PDF / 大文档）

现象：262 页 PDF 只读出约 100 页；返回带 truncated 标志；或字符数明显少于文档体量。
缺什么：工具侧对长文件的截断，不是权限问题。
去哪里补：接受截断。截断的部分通常够答题用；真需要后半部分时，按题加载对应章节的讲义替代。
补完从哪一步重试："开考"第 3 步继续装其余篇目，自检里提示"可能是长文件被截断"。

## 7. 装入后超出上下文

现象：全量装入后输出质量下降、前后文丢失、或工具报超长。
缺什么：上下文容量。
去哪里补：自动改用精简模式——只装导览、答案册、口径表，讲义按题加载。告诉用户改了模式。多门课同时开考时改成一门一门来。
补完从哪一步重试："开考"第 3 步（精简分支）。

## 8. 照片看不清

现象：题面数字、单位、选项糊或反光。
缺什么：图像质量。
去哪里补：用【?】标出看不清的字，在答复开头集中列出问用户。数字和选项宁问勿猜。
补完从哪一步重试：答题第 1 步（用户回复后重新转写该处）。

## 9. 答案册生成中断

现象：出答案册过程中途失败。
缺什么：看具体报错落在上面哪条。
去哪里补：按对应条目处理。
补完从哪一步重试：已写好的课次保留，从失败的课次继续，不从头重写。

## 10. 沙箱写不进 .exam-answer/

现象：保存资料源或本人情况时报只读或权限拒绝。
缺什么：文件系统写权限。
去哪里补：不写了。告诉用户每次开考时把链接和本人情况一起发来，流程照常。
补完从哪一步重试："设置资料源"第 2 步降级路径，直接进入"开考"。

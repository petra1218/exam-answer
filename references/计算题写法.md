# 计算题写法

遇到计算题时读。所有例题用虚构数据，不对应任何真实课程。

## 一、总原则

1. 先写假设，例如"流入流出均发生在期末"。为什么：老师评分看假设是否交代清楚，不写假设过程分打折。
2. 每个待求量写四行（见下）。为什么：过程分在系数公式和代入的数值上，四行刚好覆盖给分点。
3. 系数记法：要求的量写在前，已知的量写在斜杠后，再写利率和期数。例如已知现值求终值写 (F/P, i, n)，已知年金求现值写 (P/A, i, n)。
4. 不出现 Excel 函数名（FV、PV、NPV、RATE 之类一律不写）。为什么：手抄的答卷上出现 Excel 函数名会被视为过程缺失。
5. 多问的题分小问，每问都按四行写。

自检方法：每个系数都是"待求量在前、已知量在后"；每四行里第二行的数值和题面数字一致；结果带了单位。

## 二、四行写法

    F = P（F/P，i，n）
      = 100（F/P，10%，5）
      = 100 × 1.6105
      = 161.05（万元）

第一行：系数公式，字母形式。
第二行：把已知量、利率、期数写进系数。
第三行：系数值，保留四位小数（系数值来源见 references/计算命令与系数表.md，算数优先用命令，查不到用表，表没有用展开式）。
第四行：结果，带单位。

## 三、六个系数公式及展开式

1. 一次支付终值：F = P（F/P，i，n），展开 F = P(1+i)^n
2. 一次支付现值：P = F（P/F，i，n），展开 P = F(1+i)^(-n)
3. 等额支付终值：F = A（F/A，i，n），展开 F = A[(1+i)^n - 1]/i
4. 偿债基金：A = F（A/F，i，n），展开 A = F·i/[(1+i)^n - 1]
5. 资金回收：A = P（A/P，i，n），展开 A = P·i(1+i)^n/[(1+i)^n - 1]
6. 年金现值：P = A（P/A，i，n），展开 P = A[(1+i)^n - 1]/[i(1+i)^n]

记法都是待求量在前、已知量在斜杠后。互逆关系：(F/P)×(P/F)=1，(F/A)×(A/F)=1，(A/P)×(P/A)=1。算完用互逆关系复核。

## 四、常见题型套路与例题

例题数字全部虚构。每题只演示骨架，考场上按题面数字代入。

### 1. 有效年利率

套路：名义利率 r 每年计息 m 次，有效年利率 = (1+r/m)^m - 1。分清"名义"和"实际"，结论里写清楚哪个。

    假设：按题面计息次数计。
    有效年利率 = (1 + 12%/2)^2 - 1
      = 1.06^2 - 1
      = 0.1236
      = 12.36%

### 2. 净现值（NPV）与净年值（NAV）

套路：NPV = 逐年现金流折现加总减初始投资；NAV = NPV × (A/P, i, n)。判据：NPV ≥ 0 可行；多方案比选取 NPV 最大（互斥、同寿命）。

    假设：现金流出在期初，流入在各年末。
    NPV = -2000 + 600（P/A，10%，5）
      = -2000 + 600 × 3.7908
      = -2000 + 2274.48
      = 274.48（万元）
    NPV > 0，方案可行。

    NAV = 274.48（A/P，10%，5）
      = 274.48 × 0.2638
      = 72.39（万元/年）

### 3. 投资回收期

套路：静态回收期 = 累计净现金流由负转正的年份 - 1 + 上年累计缺口/当年净流量。判据：小于基准回收期可行。

    假设：流入在各年末。
    前 3 年累计净现金流 -100；第 4 年净流量 250。
    回收期 = 4 - 1 + 100/250
      = 3 + 0.4
      = 3.4（年）

### 4. 互斥与非互斥方案比选

套路：
- 同寿命互斥：比 NPV，取最大且 ≥ 0。
- 不同寿命互斥：比 NAV（或最小公倍数寿命法重算 NPV），取 NAV 最大。
- 非互斥（资金够）：NPV ≥ 0 的都选，按 NPV 排序。
- 资金有限的多方案组合：按 NPV 从大到小装满预算。

    假设：两方案互斥，寿命均为 6 年。
    甲 NPV = 120（万元）；乙 NPV = 150（万元）。
    乙 NPV 大，选乙。

### 5. 决策树

套路：从右往左算各决策点的期望值，每个机会节点 = Σ(概率 × 损益)；在每个决策点取期望值大的分支；最终路径上被放弃的分支画掉（文字答题就写"不选"）。

    假设：概率和损益均为题面数字。
    投产的期望值 = 0.7 × 500 + 0.3 × (-100) = 320（万元）
    不投产的期望值 = 0（万元）
    320 > 0，选投产。

### 6. 盈亏平衡

套路：产量盈亏平衡点 = 固定成本/(单价 - 单位变动成本)；生产能力利用率 = 平衡点产量/设计产量。判据：利用率越低抗风险越强。

    假设：产销一致。
    平衡点产量 = 120000/(200 - 120)
      = 120000/80
      = 1500（件）
    生产能力利用率 = 1500/5000 = 30%

### 7. 反求利率

套路：已知 P、A、n（或 F、P、n），解方程里的 i。先用系数表试凑两端夹住，再用内插（线性插值）收窄；能执行命令就用二分法命令一步到位（见计算命令与系数表）。

    假设：期末等额。
    5000 = 1500（P/A，i，5），即 (P/A，i，5) = 3.3333
    查表：(P/A，15%，5) = 3.3522，(P/A，16%，5) = 3.2743
    i ≈ 15% + (3.3522 - 3.3333)/(3.3522 - 3.2743) × 1%
      ≈ 15.24%

## 五、复核（三种算法都要做）

1. 互逆关系：(F/P)×(P/F) 应等于 1，(F/A)×(A/F) 应等于 1。
2. 一致性：按期间利率（名义/次数）和按有效年利率分别算同一题，结果应相等。
3. 复核不过就重算，不用向用户解释复核过程（答案里只呈现四行写法本身）。

## 六、与答案册的关系

出答案册时计算题同样按本文写法写，每个数值都要用 references/计算命令与系数表.md 的命令或静态表核对一遍。

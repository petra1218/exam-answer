# 计算题写法

遇到计算题时读。所有例题用虚构数据，不对应任何真实课程。系数表见 《复利系数表》，命令见 《计算命令》。

## 一、总原则：四行只用于系数题

统一顺序只有一条：先写假设，再写公式，再代入数值，最后结果带单位。

复利系数题在这个顺序里，代入行用四行写法（见第二节）：系数公式、代入系数记号、系数值、结果。其余题型按同样顺序写，但不强凑四行。
为什么：过程分在公式和代入的数值上，顺序清楚就能拿满；非系数题硬凑四行反而把决策过程写散。
自检：每个待求量都走了"假设、公式、代入、带单位结果"；系数题的代入行写进了已知量、利率、期数。

其余硬规则：
- 系数记法：要求的量写在前，已知的量写在斜杠后，再写利率和期数。例如 (F/P, i, n)、(P/A, i, n)。
- 不出现 Excel 函数名（FV、PV、NPV、RATE 之类一律不写）。
- 多问的题分小问，每问都按这个顺序写。
- 答案里的数从一而终：用表值就一路用表值，用命令值就一路用命令值，不在同一题里混。

## 二、系数题的四行写法

    F = P（F/P，i，n）
      = 100（F/P，10%，5）
      = 100 × 1.6105
      = 161.05（万元）

第一行：系数公式，字母形式。
第二行：把已知量、利率、期数写进系数记号。
第三行：系数值，保留四位小数（绝对值小于 0.1 的系数保留五位，见系数表）。
第四行：结果，带单位。

系数值来源按 《计算命令》 的三步走：算数优先用命令，不能执行命令查表，表没有用展开式。

## 三、六个系数公式及展开式

1. 一次支付终值：F = P（F/P，i，n），展开 F = P(1+i)^n
2. 一次支付现值：P = F（P/F，i，n），展开 P = F(1+i)^(-n)
3. 等额支付终值：F = A（F/A，i，n），展开 F = A[(1+i)^n - 1]/i
4. 偿债基金：A = F（A/F，i，n），展开 A = F·i/[(1+i)^n - 1]
5. 资金回收：A = P（A/P，i，n），展开 A = P·i(1+i)^n/[(1+i)^n - 1]
6. 年金现值：P = A（P/A，i，n），展开 P = A[(1+i)^n - 1]/[i(1+i)^n]

记法都是待求量在前、已知量在斜杠后。互逆关系：(F/P)×(P/F)=1，(F/A)×(A/F)=1，(A/P)×(P/A)=1。

## 四、常见题型套路与例题

例题数字全部虚构，且全部重核过。每题按"假设、公式、代入、结果带单位"写。

### 1. 有效年利率

套路：名义利率 r 每年计息 m 次，有效年利率 = (1+r/m)^m - 1。分清"名义"和"实际"，结论里写清楚哪个。

    假设：按题面计息次数计。
    公式：有效年利率 = (1 + r/m)^m - 1
      = (1 + 12%/2)^2 - 1
      = 1.06^2 - 1
      = 0.1236 = 12.36%

### 2. 净现值（NPV）与净年值（NAV）

套路：NPV = 逐年现金流折现加总减初始投资；NAV = NPV × (A/P, i, n)。判据：NPV ≥ 0 可行；多方案比选取 NPV 最大（互斥、同寿命）。

    假设：现金流出在期初，流入在各年末。
    NPV = -2000 + 600（P/A，10%，5）
      = -2000 + 600 × 3.7908
      = -2000 + 2274.48
      = 274.48（万元）
    NPV > 0，方案可行。

    NAV = 274.48（A/P，10%，5）
      = 274.48 × 0.2638
      = 72.41（万元/年）

（表值 0.2638 × 274.48 = 72.4078，四舍五入 72.41。早先写成 72.39 是错的，别再沿用。）

### 3. 投资回收期

套路：静态回收期 = 累计净现金流由负转正的年份 - 1 + 上年累计缺口/当年净流量。判据：小于基准回收期可行。

    假设：流入在各年末，前 3 年累计净现金流 -100，第 4 年净流量 250。
    公式：回收期 = 转正年份 - 1 + 上年累计缺口/当年净流量
      = 4 - 1 + 100/250
      = 3 + 0.4
      = 3.4（年）

### 4. 互斥与非互斥方案比选

套路：
- 同寿命互斥：比 NPV，取最大且 ≥ 0。
- 不同寿命互斥：比 NAV（或最小公倍数寿命法重算 NPV），取 NAV 最大。
- 非互斥（资金够）：NPV ≥ 0 的都选，按 NPV 排序。
- 资金有限的多方案组合：按 NPV 从大到小装满预算。

    假设：两方案互斥，寿命均为 6 年。
    公式：同寿命互斥取 NPV 大者。
    代入：甲 NPV = 120（万元）；乙 NPV = 150（万元）。
    结果：乙 NPV 大，选乙。

### 5. 决策树

树的文字描述（让学生照着画）：一个决策点，引出两条方案枝（全部改造、部分改造）；每条方案枝末端各接一个状态点；每个状态点引出两条概率枝（销路好 0.7、销路差 0.3），枝末写该状态下每年的损益值；概率枝末端是结果节点。

套路：从右往左算。每个状态点 = Σ(概率 × 年损益)，得期望年损益；再乘年限减投资，得每个方案的净期望值；在决策点取净期望值大的分支，被放弃的分支画掉（文字答题写"不选"）。

    假设：使用期 10 年，各年损益相同且发生在年末，概率和损益按题面。
    公式：方案净期望值 = 期望年损益 × 年限 - 投资，其中期望年损益 = Σ(概率 × 年损益)
    全部改造：
      期望年损益 = 0.7 × 100 + 0.3 × (-30) = 61（万元/年）
      净期望值 = 61 × 10 - 290 = 320（万元）
    部分改造：
      期望年损益 = 0.7 × 45 + 0.3 × 10 = 34.5（万元/年）
      净期望值 = 34.5 × 10 - 170 = 175（万元）
    结果：320 > 175，选全部改造，剪掉部分改造枝。

### 6. 盈亏平衡

套路：产量盈亏平衡点 = 固定成本/(单价 - 单位变动成本)；生产能力利用率 = 平衡点产量/设计产量。判据：利用率越低抗风险越强。

    假设：产销一致，单价与单位变动成本不随产量变。
    公式：平衡点产量 = 固定成本/(单价 - 单位变动成本)
      = 120000/(200 - 120)
      = 120000/80
      = 1500（件）
    生产能力利用率 = 1500/5000 = 30%

### 7. 反求利率

套路：已知 P、A、n（或 F、P、n）解方程里的 i。用系数表相邻两档试凑夹住，再线性插值收窄；能执行命令就用二分法一步到位（见 《计算命令》）。只查表内存在的利率档。

    假设：期末等额，5 年。
    公式：5400 = 1500（P/A，i，5），即 (P/A，i，5) = 3.6000
    代入：查表 (P/A，12%，5) = 3.6048，(P/A，15%，5) = 3.3522
      i ≈ 12% + (3.6048 - 3.6000)/(3.6048 - 3.3522) × 3%
        ≈ 12.06%
    结果：i 约 12.06%。命令二分法得 12.05%，两者在容差内。

## 五、复核（按题型给办法，带容差）

为什么加容差：表值是四位（或五位）舍入值，命令是精确值，末位天然对不上。相对误差 0.05% 以内算通过，不必重算。

- 系数题：查互逆关系 (F/P)×(P/F)=1、(F/A)×(A/F)=1、(A/P)×(P/A)=1；再查按期间利率和按有效年利率算同一题结果是否相等。互逆命令见 《计算命令》 第四节。
- 决策树、盈亏平衡、回收期：换一种算法再算一遍（决策树用逐年现金流展开核对期望，盈亏平衡用"收入=成本"反代，回收期用累计现金流表核）；或把讲义例题的原始数字代回，看是否得到讲义里的结果。

复核不过就重算，不用向用户解释复核过程，答案里只呈现上面的写法本身。

## 六、与答案册的关系

出答案册时计算题同样按本文写法写，每个数值用 《计算命令》 的命令或 《复利系数表》 的表核对一遍。

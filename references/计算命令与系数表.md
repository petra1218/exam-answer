# 计算命令与系数表

计算题要算数或查系数时读。本文是静态数据加命令模板，运行时不依赖任何脚本，命令现敲现用。

## 一、三步走

1. 能执行命令就用一行命令算。Windows 用 PowerShell，macOS 和 Linux 用 awk。
2. 不能执行命令就查下文的复利系数表：六个系数、常见利率、常见期数。
3. 表里没有的利率，用展开式手算（展开式见 references/计算题写法.md 第三节）。

三种都要复核：(F/P)×(P/F) 是否等于 1，(F/A)×(A/F) 是否等于 1；按期间利率和按有效年利率算同一题结果应相等。复核不过就重算。

命令里改三个数就能用：利率、期数、金额。命令输出就是系数值或结果，把它填进四行写法的第三行或第四行。

## 二、六大系数命令模板

Windows（PowerShell，命令行直接粘贴执行）：

    # (F/P, i, n) 一次支付终值：100 元，10%，5 期
    [math]::Round(100*[math]::Pow(1.10,5),4)

    # (P/F, i, n) 一次支付现值：100 元，10%，5 期
    [math]::Round(100/[math]::Pow(1.10,5),4)

    # (F/A, i, n) 等额支付终值：年金 100，10%，5 期
    [math]::Round(100*(([math]::Pow(1.10,5)-1)/0.10),4)

    # (A/F, i, n) 偿债基金：终值 100，10%，5 期
    [math]::Round(0.10/([math]::Pow(1.10,5)-1)*100,4)

    # (A/P, i, n) 资金回收：现值 100，10%，5 期
    [math]::Round((0.10*[math]::Pow(1.10,5))/([math]::Pow(1.10,5)-1)*100,4)

    # (P/A, i, n) 年金现值：年金 100，10%，5 期
    [math]::Round(([math]::Pow(1.10,5)-1)/(0.10*[math]::Pow(1.10,5))*100,4)

macOS 和 Linux（awk，命令行直接粘贴执行）：

    awk 'BEGIN{printf "%.4f", 100*(1.10^5)}'
    awk 'BEGIN{printf "%.4f", 100/(1.10^5)}'
    awk 'BEGIN{printf "%.4f", 100*((1.10^5-1)/0.10)}'
    awk 'BEGIN{printf "%.4f", 0.10/(1.10^5-1)*100}'
    awk 'BEGIN{printf "%.4f", (0.10*1.10^5)/(1.10^5-1)*100}'
    awk 'BEGIN{printf "%.4f", (1.10^5-1)/(0.10*1.10^5)*100}'

去掉 100* 就是纯系数值。利率 10% 写 0.10 或 1.10，7.5% 写 0.075 或 1.075。

## 三、常见题型命令模板

### 有效年利率（名义 12%，半年计息）

    PowerShell: [math]::Round([math]::Pow(1+0.12/2,2)-1,6)
    awk:        awk 'BEGIN{printf "%.6f", (1+0.12/2)^2-1}'

### 净现值（-2000 万元，1 到 5 年末各 600，10%）

    PowerShell: [math]::Round(-2000+600*(([math]::Pow(1.10,5)-1)/(0.10*[math]::Pow(1.10,5))),4)
    awk:        awk 'BEGIN{printf "%.4f", -2000+600*((1.10^5-1)/(0.10*1.10^5))}'

### 净年值（NPV 已知 274.48，10%，5 年）

    PowerShell: [math]::Round(274.48*(0.10*[math]::Pow(1.10,5))/([math]::Pow(1.10,5)-1),4)
    awk:        awk 'BEGIN{printf "%.4f", 274.48*(0.10*1.10^5)/(1.10^5-1)}'

### 投资回收期（静态，前 3 年累计 -100，第 4 年净流 250）

    PowerShell: [math]::Round(3+100/250,2)
    awk:        awk 'BEGIN{printf "%.2f", 3+100/250}'

不规则现金流就逐年累加：

    awk 'BEGIN{split("-2000 600 600 600 600 600",a," ");c=0;for(t=0;t<6;t++){c+=a[t+1]/1.10^t};printf "%.2f",c}'

### 决策树期望值（0.7×500 + 0.3×(-100)）

    PowerShell: [math]::Round(0.7*500+0.3*(-100),2)
    awk:        awk 'BEGIN{printf "%.2f", 0.7*500+0.3*(-100)}'

### 盈亏平衡（固定 120000，单价 200，单位变动 120）

    PowerShell: [math]::Round(120000/(200-120),0)
    awk:        awk 'BEGIN{printf "%.0f", 120000/(200-120)}'

### 反求利率（5000 = 1500 每年，5 年，二分法解 i）

    PowerShell: $lo=0.0;$hi=1.0;for($k=0;$k -lt 200;$k++){$m=($lo+$hi)/2;$v=1500*(([math]::Pow(1+$m,5)-1)/($m*[math]::Pow(1+$m,5)));if($v -gt 5000){$lo=$m}else{$hi=$m}};[math]::Round(($lo+$hi)/2*100,2)

    awk:        awk 'BEGIN{lo=0;hi=1;for(k=0;k<200;k++){m=(lo+hi)/2;v=1500*((1+m)^5-1)/(m*(1+m)^5);if(v>5000)lo=m;else hi=m};printf "%.2f%%",(lo+hi)/2*100}'

上面命令解的是年金现值方程；改 F、P 方程就把 v 换成 P*(1+m)^n 与目标 F 比较。

## 五、复核命令

    # (F/P)×(P/F) = 1
    PowerShell: [math]::Round([math]::Pow(1.10,5)*(1/[math]::Pow(1.10,5)),4)
    awk:        awk 'BEGIN{printf "%.4f", (1.10^5)*(1/1.10^5)}'

    # (F/A)×(A/F) = 1
    PowerShell: [math]::Round((([math]::Pow(1.10,5)-1)/0.10)*(0.10/([math]::Pow(1.10,5)-1)),4)
    awk:        awk 'BEGIN{printf "%.4f", ((1.10^5-1)/0.10)*(0.10/(1.10^5-1))}'

    # 半年计息 12% 对比有效年利率 12.36% 算同一笔终值应相等
    PowerShell: [math]::Round(100*[math]::Pow(1+0.12/2,10),4)
    awk:        awk 'BEGIN{printf "%.4f", 100*(1.1236^5)}'
